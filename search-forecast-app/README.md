# 🔍 Search Forecast AppApp professionale per la previsione dei volumi di ricerca web, basata su dati storici, parametri socio-economici e modelli di forecasting avanzati. Deployata su Netlify con architettura Jamstack + funzioni serverless.## 🏗️ Architettura- **Frontend**: Vue 3 + Vite + Chart.js- **Orchestrazione**: Netlify Functions (Node.js 18)- **ML Inference**: Servizio esterno (FastAPI/Python) con modello Prophet/ONNX- **Pattern**: Request → Job ID → Polling (supera limiti timeout serverless)## 🚀 Deploy1. Clona il repository: `git clone <repo-url>`2. Configura le variabili d'ambiente in Netlify (Dashboard → Settings → Environment Variables)3. Collega il repo a Netlify: `app.netlify.com` → Import Existing Project → GitHub4. Deploy automatico ad ogni push su `main`## 🛠️ Sviluppo Locale```bashcd frontendnpm installnpm run dev# In un altro terminale: netlify dev
